# 分节撰写研究报告

## 输入

一个 task packet，包含：本节标题与章节边界、可用事实切片、上期相关判断、写作约束、
反例。不含其他章节的内容——刻意如此，避免后写的节去迎合已写下的判断。

## 四段结构

一节好的分析文字通常是四段，而不是一段：

1. **判断**：一句话说清这节要论证什么
2. **证据**：数字或事件，全部用占位符引用
3. **归因**：为什么会这样（这一层最容易把推断写成事实）
4. **边界**：这个判断在什么条件下失效、还需要什么证据

第 3、4 段是可读性与可信度的分水岭。只写 1、2 段的报告像数据播报；
只写 1、3 段的报告像观点专栏；四段齐全才是研究。

## 章节边界纪律

| 章节 | 该做 | 不该做 |
|---|---|---|
| 市场表现 | 描述事实、识别异常 | 承担完整基本面解释 |
| 定价环境 | 解释外部条件变化 | 提前展开个券估值结论 |
| 新增信息 | 说明现金流假设为何调整 | 把公告摘要当研究结论 |
| 估值配置 | 价格与现金流预期结合 | 给无条件的买卖建议 |

越界写会与前后的章节重复，读者读到的信息密度反而下降。

## 口径纪律

涉及以下指标时，首次出现必须声明口径：

- **板块收益**：等权还是市值加权？含不含分红？
- **P/NAV**：用总市值还是流通市值加权？样本是否含新上市？
- **换手率**：分母用流通市值还是总市值？是否除以交易日数？
- **全收益 vs 价格指数**：差多少、差在哪

同一份报告里同类指标只能有一个口径。出现两个就是事故，不是"参考值"。

## 反例

> ✗ 本周市场分化明显，部分标的回调较大。

没有数字、没有判断、没有归因。删掉也不损失信息。

> ✗ 本周首尾相差 5.8 个百分点。

5.8 从哪来？如果不是事实库里的数，就是心算的，会被审计拦下。

> ✓ 涨幅居前的是 {{M:mover.top_name}}（{{M:mover.top_value}}），
> 跌幅最大的是 {{M:mover.bottom_name}}（{{M:mover.bottom_value}}），
> 首尾分化显著。我们认为下跌一侧可归因为三类……需要说明的是，
> 上述分类属于事后归因，单周数据不足以区分一次性冲击与趋势性重定价。

有判断、有证据、有归因、有边界。

## 检查清单

写完一节，自查：

- [ ] 至少一句可被检验的判断
- [ ] 所有数字都是占位符
- [ ] 归因处声明了"属于事后归因"或类似限定
- [ ] 口径敏感指标的首次出现处声明了口径
- [ ] 没有"必然""一定"这类绝对化措辞
- [ ] 判断性章节交代了与上期的关系
- [ ] 字数在 150–400 之间
