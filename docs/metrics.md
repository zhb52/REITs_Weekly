# 指标定义与口径

本文件是口径的**唯一文字说明**。代码里凡是标了 `formula_id` 的地方，都应能在这里找到对应条目。

---

## 1. 周涨跌幅（主口径）

```
周涨跌幅(%) = (本周收盘价 − 上周收盘价 + 本周每份分红) ÷ 上周收盘价 × 100
formula: weekly_total_return
```

**为什么不用前复权**：前复权序列在每次分红后会整体重算历史价格，导致"上周收盘价"随本期分红变化，跨期不可比。用"不复权 + 分红"可以把价格变动与分红收益分开，这也是解释"价格指数与全收益指数相差 15bp 来自 5 只集中除息"的算法基础。

**已知陷阱**：终端导出的"本周涨跌幅（%）"列实际存的是小数（`0.0094637` 表示 0.95%）。必须在归一化层显式乘 100，`G-UNIT-01` 会在量级异常时兜底。

## 2. 分红贡献

```
分红贡献(百分点) = 本周每份分红 ÷ 上周收盘价 × 100
formula: dividend_contribution
勾稽：主口径 − 价格口径 ≡ 分红贡献
```

## 3. 板块等权收益

```
板块等权(%) = 板块内可比样本 ret_total 的算术平均
formula: board_eq_return
```

**样本规则**：仅含本期有完整比较期的标的。本期新上市的（无上期收盘价）不参与板块等权，单列观察。

**与官方指数的区别**：中证 REITs 指数是市值加权、含分红再投资。两者不可混用，正文凡并列出现必须分别命名。

## 4. 市场广度

```
上涨 / 下跌 / 持平 = count(ret > 1e-9) / count(ret < -1e-9) / 其余
formula: breadth
勾稽：上涨 + 下跌 + 持平 ≡ 可比样本数
```

阈值取 `1e-9` 而非 `0`：浮点减法会产生 `1e-16` 量级噪声，用 `> 0` 判断会把价格持平的个券误计为上涨。

## 5. P/NAV

```
P/NAV = 收盘价 ÷ 单位净值
中位数 / 均值 / 市值加权（用总市值，不是流通市值）
溢价/折价 = P/NAV ≥ 1 / P/NAV < 1
formula: pnav_summary, pnav_by_board
```

**只用可比样本**：本期新上市标的的 P/NAV 恒接近 1.00，计入会把中位数整体拉向 1。实测 96 只算得 1.039，94 只算得 1.055。

**数据限制**：P/NAV 直接取终端字段，不做 NAV 桥接与评估调整。若终端缺该字段，本模块返回 NaN 并在门禁中记为缺口，**不估算**。

## 6. 换手率（TR-01）

```
全周日均换手率(%) = Σ本周成交额 ÷ Σ流通市值 ÷ 交易日数 × 100
formula_id: TR-01
```

**为什么单列一条**：2026-W45 期同一指标出现过三个值——底稿 0.36%、正文 0.31%、按上式复算 0.327%。三者互不相符，其中 0.31% 用现有数据无法复现。2026-11-14 经作者确认，统一采用上式（可被外部复现：任何人拿公开成交额与流通市值都能算出同一个数）。

**与"等权平均个券换手率"的区别**：后者会给出更低的数值，但依赖样本选择，不可复现，仅作敏感性参考，不进入正文。

**上周换手率**：用**本期流通市值**作分母重算，与本周同口径。不等于终端公布的"上周日均换手率"（那用上周市值）。因此环比表述应写"较上周同口径回落 X 个百分点"。

## 7. 成交集中度

```
前 N 大板块成交额占比(%) = Σ前 N 大板块成交额 ÷ 全市场成交额 × 100
```

## 8. 指数收益

- **全收益指数**：含分红再投资，是中证 REITs 的主基准（代码 932047）
- **价格指数**：不含分红（代码 932006）
- 两者之差即分红贡献，年初至今口径同理

## 9. 年初至今（YTD）

```
YTD(%) = (本期末价 − 上年末价 + 期间累计分红) ÷ 上年末价 × 100
```

**当前限制**：缺 2025 年末价格与全年分红台账，故 `ytd_return` 在缺数据时返回 `NotAvailable`，**不近似、不硬凑**。正文中的 YTD 数字来自指数本身（指数编制方已处理分红），而非自算个券 YTD。
